# RetainIQ

### Predictive workforce intelligence for smarter employee retention.

## Problem Statement

Employee attrition is a major challenge for organizations. Identifying employees who are more likely to leave can help HR teams take timely and informed retention actions.

RetainIQ aims to build a machine learning-based system that predicts an employee's attrition risk using employee and workplace-related factors.

The system will not only predict whether an employee is likely to leave, but will also provide:

- Attrition probability
- Risk level
- Key factors contributing to the prediction
- Actionable retention suggestions
